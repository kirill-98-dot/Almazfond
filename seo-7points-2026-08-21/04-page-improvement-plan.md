# 4. План улучшения существующих страниц

## Решение на текущем срезе

15 августа уже были изменены title, description и alt у десяти ключевых URL. До контрольной даты 29 августа повторно менять сниппеты нельзя: иначе невозможно измерить результат первой версии. Сейчас выполняются только изменения, не сбивающие эксперимент.

## Что внедрено 21 августа

На 11 посадочных страницах и в основном гайде в нижний блок перелинковки добавлена карточка «Каталог изделий из Златоуста» со ссылкой на `/categories/`. Это направляет запросы о магазине, каталоге и изделиях из Златоуста с главной и подарочных страниц на целевой каталог. Проверка после выкладки: 11 из 11 URL отвечают HTTP 200, карточка присутствует на каждой странице, в блоках осталось 4-5 карточек.

## Новые посадочные

На текущем массиве данных новый URL не требуется. Новая страница создается только если одновременно выполнены три условия: отдельный интент, не менее 20-30 релевантных запросов в кластере и отсутствие подходящей существующей страницы.
