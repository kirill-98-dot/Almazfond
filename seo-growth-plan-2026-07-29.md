# План SEO-роста Almazfond на 90 дней

Дата базового среза: 29.07.2026  
Период данных Яндекс.Вебмастера: 30.04.2026–29.07.2026  
Горизонт выполнения: 12 недель  
Основная цель: увеличить небрендовый органический спрос и обращения без создания конкурирующих друг с другом страниц.

## 1. Что уже выполнено в рамках первого пункта

1. Сборщик Яндекс.Вебмастера переведён с одной страницы API на полную пагинацию.
2. Получено 866 запросов вместо прежних 500.
3. API обработан за две страницы, дублей между страницами не обнаружено.
4. Добавлен автоматический анализатор семантики.
5. Для каждого запроса определяются:
   - кластер;
   - релевантность;
   - приоритет;
   - предполагаемая целевая страница;
   - необходимость ручной привязки.
6. Исправлены ложные совпадения, например «мечеть» больше не относится к оружию.
7. Общие запросы про чужие мастерские не попадают в коммерческий приоритет автоматически.
8. Единичный показ не делает запрос задачей P1: для P1 и P2 требуется минимум два показа.

Результаты сохраняются локально в полном CSV, а в GitHub публикуется обезличенная рабочая сводка без OAuth-токенов.

Критерии:

- средняя позиция 8–20;
- минимум два показа;
- запрос соответствует ассортименту;
- существует подходящая страница или карточка.

### P2 — работа после проверки P1

Критерии:

- средняя позиция 20–35;
- минимум два показа;
- понятная коммерческая цель.

Основные запросы:

- `златоуст сувениры магазин` — 21,3;
- `златоуст подарки` — 25,3–28,8;
- `златоуст сувениры` — 26,0;
- `златоуст подарки для мужчин` — 29,7;
- `сувениры из Златоуста` — 30,0;
- `сувенирный пожарный топор` — 23,5;
- `часы глобус` — 30,5;
- `часы с волком` — 32,5.

### Не оптимизировать автоматически

- названия чужих производителей и мастерских;
- случайные информационные запросы;
- запросы «как сделать своими руками»;
- маркетплейсы и объявления;
- неоднозначные фразы без подходящего товара;
- юридически чувствительные оружейные формулировки;
- единичные показы без устойчивой динамики.

## 6. План по неделям

### Неделя 1 — база измерения

1. Зафиксировать текущую выгрузку как неизменяемый baseline.
2. Настроить еженедельный запуск полного сбора Вебмастера.
3. Собирать отдельно:
   - бренд;
   - небренд;
   - посадочные;
   - категории;
   - товары;
   - P1 и P2.
4. Зафиксировать индексацию всех новых посадочных в Яндексе.
5. Зафиксировать индексацию тех же URL в Google Search Console.
6. Проверить sitemap:
   - URL присутствует;
   - код ответа 200;
   - canonical совпадает;
   - `lastmod` обновляется только при реальном изменении.
7. Проверить Метрику:
   - отправка формы;
   - клик по телефону;
   - Telegram/MAX;
   - «Уточнить наличие»;
   - заявка с посадочной;
   - переход из посадочной в каталог.

Критерий готовности: для каждого приоритетного URL есть исходные показы, клики, позиция, индексация и конверсионные события.

### Неделя 2 — общий каталог и московский интент

Целевой URL: `/categories/`.

1. Проверить, какая страница фактически показывается по запросам:
   - «златоуст подарки официальный сайт»;
   - «магазин златоуст в москве»;
   - «златоуст сувениры магазин»;
   - «златоуст подарки»;
   - «златоуст сувениры».
2. Сравнить текущие `title`, description, H1 и первый экран.
3. Не менять визуальный H1, если интент уже понятен.
4. Добавить в title и description естественные признаки:
   - подарки и сувениры из Златоуста;
   - официальный каталог;
   - галерея в Москве.
5. Убедиться, что адрес и телефон совпадают на сайте, в Яндекс Бизнесе и контактах.
6. Добавить 3–5 контекстных ссылок на `/categories/`:
   - с главной;
   - со страницы контактов;
   - с VIP-подарков;
   - с подарков мужчине;
   - из футера только при естественной формулировке.
7. Проверить, что анкор не повторяется механически.

Критерий готовности: один основной URL закреплён за общими запросами Златоуста, конкурирующих страниц нет.

Статус на 7 августа 2026 года: техническая и контентная часть выполнена. Метаданные `/categories/` обновлены, добавлены контекстные ссылки, страница отправлена на повторный обход в Яндекс и sitemap повторно отправлен в Google. В исходных данных Яндекс по двум общим запросам пока выбирает главную страницу, поэтому окончательная проверка закрепления URL назначена после переобхода через 7-14 дней.

### Неделя 3 — VIP и подарочный интент

Целевой URL: `/vip-podarki/`.

1. Сверить запросы P1 с содержанием страницы.
2. Усилить смысловые формулировки без переспама:
   - эксклюзивный подарок;
   - изделие ручной работы;
   - подарок из Златоуста;
   - официальный или торжественный повод;
   - упаковка и помощь с выбором.
3. Проверить сниппет:
   - title читается целиком;
   - description объясняет ассортимент и доставку;
   - нет повторения H1.
4. Добавить ссылки на VIP-страницу из 6–10 подходящих категорий и товаров.
5. Из VIP-страницы вести на 6–12 реальных товаров, доступных для заказа.
6. Не добавлять товар с нулевой ценой как главный вариант.
7. Проверить каннибализацию с `/elitnye-podarki/`.

Критерий готовности: VIP и элитные подарки имеют разные интенты и не повторяют одинаковый SEO-текст.

1. Повторить полный экспорт Вебмастера.
2. Сравнить с baseline:
   - показы;
   - клики;
   - CTR;
   - средняя позиция;
   - число запросов в топ-10, топ-20 и топ-30.
3. Отдельно сравнить бренд и небренд.
4. Проверить новые посадочные после периода накопления данных.
5. Для выросших страниц:
   - сохранить интент;
   - добавить ассортимент;
   - усилить внутренние ссылки.
6. Для страниц без роста проверить:
   - индекс;
   - каннибализацию;
   - несоответствие интенту;
   - слабый ассортимент;
   - техническую скорость.
7. Только после данных решать вопрос о новых страницах или гайдах.

## 7. Правила для новых посадочных

В течение первых 60 дней новые гайды не создавать.

Для каждой существующей посадочной должны быть:

1. Один главный поисковый интент.
2. Уникальные title, description и H1.
3. Отличающийся набор сценариев и товаров.
4. Ссылки из 2–4 категорий.
5. Ссылки на 6–12 подходящих товаров.
6. Ссылка на существующий гайд, если он помогает выбору.
7. Ссылки обратно из категорий и товаров.
8. Canonical на себя.
9. Код ответа 200.
10. Присутствие в sitemap.
11. Корректный `lastmod`.
12. Отсутствие конкуренции с соседней посадочной.

## 8. KPI

### Через 30 дней

- все новые посадочные находятся в индексе Яндекса и Google;
- минимум 5 релевантных P1 переходят в топ-10;
- общая категория получает клики по кластеру Златоуста;
- нет Product/Offer с ценой 0;
- цели Метрики фиксируют основные обращения;
- сформирован еженедельный отчёт по бренду и небренду.

### Через 60 дней

- 10–15 небрендовых запросов переходят в топ-10;
- показы подарочного кластера растут не менее чем на 25%;
- показы кластера Златоуста растут не менее чем на 25%;
- минимум четыре новые посадочные получают устойчивые показы;
- мобильный LCP ключевых шаблонов улучшен;
- получены первые качественные внешние упоминания.

### Через 90 дней

- небрендовые органические клики растут на 35–50% к сопоставимому периоду;
- 20+ релевантных запросов находятся в топ-10;
- основные посадочные закрепляются в топ-20;
- растёт число обращений из органики, а не только посещений;
- есть повторяемый процесс: данные → гипотеза → изменение → проверка.

## 9. Еженедельный отчёт

Каждый понедельник:

1. Полный экспорт Яндекс.Вебмастера.
2. Экспорт Google Search Console после накопления данных.
3. Сравнение 7 дней к предыдущим 7 дням.
4. Сравнение 28 дней к предыдущим 28 дням.
5. Таблица:
   - URL;
   - запрос;
   - показы;
   - клики;
   - CTR;
   - позиция;
   - изменение позиции;
   - конверсии.
6. Отдельные итоги по:
   - бренду;
   - подарочным посадочным;
   - категориям;
   - товарам;
   - P1/P2.
7. Не более пяти новых задач на неделю, ранжированных по ожидаемому эффекту.

## 10. Критерий принятия SEO-изменения

Изменение считается завершённым, когда:

1. Есть исходная метрика.
2. Определён один целевой URL.
3. Нет каннибализации.
4. Изменение опубликовано и проверено на мобильном/десктопе.
5. URL отвечает 200 и остаётся индексируемым.
6. Sitemap и canonical корректны.
7. Изменение записано в журнал.
8. Через 14–28 дней выполнена повторная проверка.

## 11. Что не делать

- не создавать десятки страниц под единичные запросы;
- не переписывать одновременно все посадочные;
- не менять URL без необходимости;
- не закупать массовые ссылки;
- не использовать одинаковый SEO-текст на соседних страницах;
- не считать брендовый рост доказательством роста коммерческой семантики;
- не оптимизировать сайт под запросы чужих мастерских;
- не менять страницу без baseline и даты проверки.

## 12. Следующее конкретное действие

Начать с `/categories/` и двух запросов:

1. `златоуст подарки официальный сайт`;
2. `магазин златоуст в москве`.

Сначала зафиксировать текущий сниппет и входную страницу, затем скорректировать метаданные и внутренние ссылки. Через 14 дней проверить индексацию сниппета, через 28 дней — позиции, показы, клики и обращения.
